# Установка OhMyCode на Ubuntu

Текущая сборка — **OhMyCode Dev 2.0.24-ohmycode.4**, для Ubuntu на процессорах Intel/AMD x86-64.
Она устанавливается отдельно от обычного OpenCode. Это тестовая сборка; автоматические обновления пока отключены.

## Установка готового пакета

1. Скопируйте файл `ohmycode-dev-2.0.24-ohmycode.4-linux-amd64.deb` на другой компьютер: через флешку, SCP или файловый обмен. Готовый пакет пока не опубликован в GitHub Releases.
2. Откройте терминал в папке с файлом и выполните:

   ```sh
   dpkg --print-architecture
   # Должно быть amd64.
   sudo apt install ./ohmycode-dev-2.0.24-ohmycode.4-linux-amd64.deb
   ```

   APT установит системные зависимости. Интернет для этого может понадобиться.

3. Запустите **OhMyCode Dev** из меню приложений. Или выполните:

   ```sh
   /opt/OhMyCodeDev/ru.ohmylama.ohmycode.dev
   ```

4. Войдите в свой аккаунт LAMA или подключите свой API-ключ. Чужие ключи в установщик не включены. На другом компьютере вход нужно выполнить заново.

Node, Bun и исходники для запуска готового пакета не нужны. Работа оплачивается с API-баланса LAMA; подписка на веб-чат его не заменяет.

Не запускайте приложение через `sudo` или с `--no-sandbox`. Установщик настраивает права Chromium sandbox.

## Обновление и удаление

Начиная со сборки `2.0.24-ohmycode.5`, приложение проверяет обновления при запуске и каждые 10 минут. После загрузки нажмите «Установить и перезапустить». Ubuntu может запросить пароль для установки пакета.

Со сборки `.4` на `.5` нужно перейти вручную один раз: закройте OhMyCode, скачайте новый `.deb` и установите той же командой `sudo apt install ./имя-пакета.deb`.
Настройки и диалоги сохраняются в `~/.config/ru.ohmylama.ohmycode.dev`.
Данные с другого компьютера автоматически не переносятся.

Удаление приложения:

```sh
sudo apt remove ohmycode-dev
```

Личные данные остаются на диске. ARM64 требует отдельной сборки; этот пакет для него не подходит.

## Как собрать следующий пакет из исходников

На Linux x86-64 установите Git, Node.js 24 и Bun 1.4.2. Затем:

```sh
git clone --branch v2 https://github.com/warcivil/ohmycode.git
cd ohmycode
bun install
bun run package:ohmycode:deb
```

Пакет появится в `packages/desktop/dist/`. Команда собирает интерфейс, встроенный сервер и установщик; личные настройки и API-ключи в пакет не попадают.
Перед новой распространяемой сборкой увеличьте суффикс `-ohmycode.N` в `script/build-ohmycode.ts`, чтобы APT распознал обновление.
